NMD Dispatch Planner – one-time setup

Run this once after creating the Firebase project. It creates the logins and (optionally) brings over your data from the claude.ai version. Afterwards open the planner.

1. Data from the claude.ai version (optional)

Choose nmd-data-backup-….json to bring over the pending SO, plans, quantities, priorities and the list of logins. Skip this to start fresh.

2. Logins and passwords

Same click-based logins as the app. Type a password for each one (you can keep the old passwords). The first Admin row is used to run this setup.
